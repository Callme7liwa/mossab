# Aura Estates Insight

This repository contains the Aura Estates Insight web application (Vite + React) and the Node/Express backend (located in `server/`).

Getting started locally

1. Clone the repository:

```bash
git clone <YOUR_GIT_URL>
cd aura-estates-insight
```

2. Install dependencies and run the dev server:

```bash
npm ci
npm run dev
```

3. Backend (server):

```bash
cd server
npm ci
npm run dev
```

Technologies used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
